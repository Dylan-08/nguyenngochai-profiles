# Trang giới thiệu cá nhân – Nguyễn Ngọc Hải

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub, ví dụ `nguyenngochai-profile`.
2. Upload `index.html`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main` và thư mục `/ (root)`, rồi Save.
6. Link trang sẽ có dạng `https://<username>.github.io/nguyenngochai-profile/`.

Trang gồm: họ tên, ngày sinh, địa chỉ, quá trình học, chuyên môn, kinh nghiệm, sở thích và thành tích.
